
This directory contains car brand logos for the Rentify website.

Currently, the website uses fallback text rendering when actual logo images are not available.
To add actual logos, place properly named logo images in this directory with the following naming convention:

- audi.png
- bmw.png
- mercedes.png
- toyota.png
- volkswagen.png
- honda.png
- ford.png
- hyundai.png
- nissan.png
- kia.png
- mazda.png
- chevrolet.png
- jeep.png
- landrover.png
- tesla.png

All images should be transparent PNGs with the brand logo clearly visible.
Recommended size: 200x100px or similar aspect ratio.
